Support & aide
Les réponses aux questions les plus fréquentes. Touchez une question pour la déplier.

Le PC qui pilote l'écran doit être allumé, sur le même réseau que votre téléphone, et le serveur lancé (python remote_server.py). Une fois ces points vérifiés, touchez Réessayer.

Oui. Tout passe par le réseau local — aucune donnée ne sort sur Internet. Si vous changez de Wi-Fi, reconnectez-vous à celui du PC.

Non. Le jeton d'accès est mémorisé dans le lien. Ajoutez la page à l'écran d'accueil (Partager → Sur l'écran d'accueil) et rouvrez-la directement.

Vérifiez qu'au moins une page est dans la playlist, touchez Lecture, et si les horaires sont activés, assurez-vous d'être dans la plage (hors plage = affichage en pause).

Playlist → Modifier → Horaires d'affichage : activez, réglez début/fin et les jours actifs. En dehors, la rotation se met en veille.

Certains portails ferment la session sur inactivité. wee rotate simule une activité discrète en continu pour l'éviter. Si cela persiste, augmentez la fréquence de rafraîchissement (Modifier) ou utilisez un compte dédié à l'écran.

Modifier → icône horloge sur la page → choisissez la durée. Sans réglage, l'intervalle par défaut s'applique.

Modifier → appui long sur une page → glissez-la à la position voulue, puis relâchez.

Une seule extension doit piloter l'écran. Ouvrez chrome://extensions (et Edge si installé), supprimez le doublon, puis redémarrez le serveur.

Les pages Canva sont rechargées périodiquement : réglez l'intervalle dans Modifier → Rafraîchissement auto → Canva (en minutes).

Réglages → Sauvegarde automatique : la playlist est conservée sur le PC. Touchez Restaurer pour la récupérer.

C'est recommandé : un compte en lecture seule dédié à l'affichage limite les risques si l'écran reste connecté en continu (bonne pratique de sécurité).
