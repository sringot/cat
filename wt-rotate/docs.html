wee rotate
Remote Control

Un système complet de pilotage d'affichage kiosque : extension Chrome, serveur Python et télécommande PWA installable sur le téléphone. Gérez vos rotations d'URL depuis votre canapé.

Chrome / Edge MV3 Python 3.8+ PWA — iOS & Android LAN uniquement
01

Présentation

wee rotate est conçu pour un usage simple : une télé ou un écran de bureau doit afficher en boucle un ensemble de pages web (tableaux de bord, slides Canva, dashboards, pages d'info…). L'extension Chrome gère la rotation ; la télécommande PWA permet de tout piloter depuis le téléphone, sans toucher le PC kiosque.

Cas d'usage typiques

Affichage dynamique
Slides Canva, Google Slides, Notion, Airtable — tout ce qui s'affiche dans un navigateur.
Tableau de bord
Grafana, Metabase, Google Analytics — les outils de monitoring qui tournent en boucle.
Espace d'accueil
Écran de bienvenue, menu du jour, planning hebdomadaire affiché à l'entrée d'un bureau ou d'un espace de travail.
Diffusion vidéo
Lecture de vidéos YouTube en rotation, avec contrôle de volume depuis le téléphone.
Horaires planifiés
L'affichage se lance et s'arrête automatiquement selon les jours de la semaine et les plages horaires définies.
Messages urgents
Envoyez un message en surimpression sur l'écran en deux secondes, depuis n'importe où dans le bâtiment.
02

Architecture technique

Le système repose sur trois composants qui communiquent en temps réel via WebSocket sur le réseau local. Tout reste dans le LAN — aucune donnée ne sort vers internet.

Téléphone (iOS / Android)
PWA — control.html
Application web progressive installable sur l'écran d'accueil. Interface de télécommande : lecture, pause, navigation, volume, messages, gestion de playlist. Se connecte au serveur Python via WebSocket.
WebSocket ws://<ip>:8765 · token JWT
PC kiosque · Python
remote_server.py · aiohttp
Serveur HTTP + WebSocket asynchrone (port 8765). Sert les fichiers statiques de la PWA, relaie les commandes entre le téléphone et l'extension, met en cache l'état et les captures d'écran pour les mobiles qui se reconnectent. Gère aussi la bibliothèque de playlists et la sauvegarde automatique de session.
WebSocket ws://localhost:8765
PC kiosque · Chrome / Edge
Extension MV3 — background.js
Service Worker Manifest V3. Ouvre et gère une fenêtre kiosque dédiée, pilote la rotation via des alarmes Chrome (chrome.alarms), injecte l'overlay de messages, capture des screenshots de l'onglet actif et les envoie au serveur. Se reconnecte automatiquement au serveur toutes les 500 ms en cas de déconnexion.
Fenêtre kiosque — Chrome
Onglets kiosque (URLs en rotation)
L'extension ouvre une fenêtre séparée contenant un onglet par URL de la playlist. La rotation consiste à rendre l'onglet suivant actif toutes les N secondes. L'overlay de messages est injecté dans chaque onglet via chrome.scripting.

Fichiers clés

background.js
Point d'entrée du Service Worker. Importe les modules bg/ et définit tous les listeners Chrome (alarms, tabs, runtime…).
bg/config.js
Configuration par défaut et migration de schema. Intervalle de 30 s par défaut, horaires Lu–Ve 08:00–18:00.
bg/tabs.js
Logique de rotation, gestion de la fenêtre kiosque, vérification des horaires, rechargement automatique des pages.
bg/remote.js
Client WebSocket de l'extension. Connexion au serveur local, envoi des états et captures, réception et exécution des commandes.
bg/overlay.js
Injection de l'overlay de messages texte dans les onglets kiosque via chrome.scripting.executeScript.
remote_server.py
Point d'entrée du serveur. Détecte l'IP LAN, génère le QR code, lance le serveur aiohttp sur le port 8765.
server/ws_handler.py
Cœur du relais WebSocket. Gère les deux types de connexions (extension / mobile), la détection de doublon d'extension et le keepalive.
server/auth.py
Token hexadécimal de 16 caractères persisté dans .wt_token. Comparaison en temps constant pour éviter les attaques timing.
server/library.py
Bibliothèque de playlists nommées, stockée localement. Sauvegarde et chargement sans passer par l'extension.
server/sys_audio.py
Contrôle du volume système Windows via pycaw. Si absent, le volume est appliqué directement sur l'élément <video>.
control.html
PWA télécommande, servi par le serveur Python sur /app. Application mobile complète en un seul fichier HTML.
popup.html / popup.js
Interface de l'extension dans Chrome. Affiche le QR code, le statut de connexion et la liste des URLs configurées.
03

Installation

Tout s'installe sur le PC kiosque. La télécommande n'a pas besoin d'installation séparée : elle est servie automatiquement par le serveur Python.

Prérequis

Python 3.8 ou supérieur doit être installé sur le PC kiosque. Google Chrome ou Microsoft Edge (Chromium) doit être disponible.

1. Dépendances Python

$ pip install aiohttp qrcode pycaw

aiohttp est le serveur WebSocket. qrcode génère le QR code dans la popup. pycaw (optionnel, Windows) pilote le volume système Windows. Sans lui, le volume est appliqué sur l'élément vidéo dans l'onglet.

2. Charger l'extension Chrome

  • 1
    Ouvrez Chrome ou Edge Naviguez vers chrome://extensions (ou edge://extensions)
  • 2
    Activez le mode développeur Interrupteur en haut à droite de la page des extensions
  • 3
    Cliquez sur « Charger l'extension non empaquetée » Sélectionnez le dossier wt-rotate (celui qui contient manifest.json)
  • 4
    Épinglez la popup Cliquez sur l'icône de puzzle dans la barre Chrome → épinglez « wee rotate »

3. Démarrage automatique (Windows)

Pour que le serveur démarre automatiquement à chaque connexion Windows, exécutez ce script en tant qu'Administrateur : 

$ python setup_autostart.py

Le script crée une tâche planifiée Windows qui lance le serveur 30 secondes après chaque session (le temps que le réseau soit disponible), avec relance automatique en cas de plantage. Il crée également un raccourci du navigateur dans le dossier Démarrage.

Après l'autostart

Configurez le navigateur sur « Ouvrir la page Nouvel onglet » au démarrage (et non « Reprendre »), pour éviter qu'une ancienne fenêtre kiosque soit restaurée en doublon.

Pour le login automatique Windows : Win + R → netplwiz → décochez « Les utilisateurs doivent entrer un nom d'utilisateur... »

04

Démarrage

Trois étapes pour avoir la télécommande dans la main en moins de deux minutes.

  • 1
    Lancez le serveur sur le PC kiosque Dans un terminal dans le dossier wt-rotate : 
$ python remote_server.py
  • 2
    Ouvrez la popup de l'extension Cliquez sur l'icône wee rotate dans Chrome → un QR code s'affiche avec l'adresse LAN et le token d'authentification
  • 3
    Scannez le QR code avec votre téléphone Le guide d'installation PWA s'ouvre — ajoutez l'app à l'écran d'accueil pour une expérience native. L'URL contient déjà le token : pas besoin de le ressaisir après chaque redémarrage du serveur.

Le serveur affiche dans son terminal l'IP locale, l'URL et le token en cours : 

╔══════════════════════════════════════════╗
║    wt-rotate Remote Control Server       ║
╠══════════════════════════════════════════╣
║  IP locale  : 192.168.1.42              ║
║  URL mobile : http://192.168.1.42:8765/ ║
║  Token auth : a1b2c3d4e5f6a7b8          ║
║  QR code    : OK                        ║
╚══════════════════════════════════════════╝
Note sur le token

Le token est généré une seule fois et sauvegardé dans .wt_token. Les redémarrages du serveur ne l'invalident pas — votre QR code scanné reste valide indéfiniment. Pour renouveler le token (ex. changement de téléphone), supprimez le fichier .wt_token puis redémarrez le serveur.

05

La télécommande

La PWA se compose de trois onglets : Accueil (contrôles principaux), Playlist (gestion de la liste d'URLs) et Réglages. Voici le détail de chaque fonctionnalité.

Onglet Accueil

Contrôles de lecture
⏮ Précédent / ⏭ Suivant
Passe immédiatement à l'URL précédente ou suivante dans la playlist, sans attendre la fin du timer.
⏸ Pause / ▶ Lecture
Met la rotation en pause (l'URL en cours reste à l'écran) ou la reprend. L'état est conservé même si l'extension se reconnecte.
Volume
Curseur de 0 à 100 %. Sur Windows avec pycaw installé, règle le volume système. Sinon, règle le volume de l'élément vidéo dans l'onglet actif.
Indicateur d'état
La pastille en haut à droite indique si l'extension est connectée (vert), en attente (jaune) ou déconnectée (rouge). Un message d'avertissement s'affiche si l'extension est absente.

Aperçu en direct

Quand la rotation est active, un aperçu miniature de l'onglet kiosque actuel est affiché dans la télécommande. L'extension capture une capture d'écran et l'envoie au serveur, qui la met en cache et la diffuse à tous les mobiles connectés. Un bouton de rafraîchissement manuel est disponible si l'image n'est pas à jour.

Mode Spotlight

Afficher une URL immédiatement

Le champ « Afficher une URL » en bas de l'onglet Accueil permet de pousser n'importe quelle URL sur l'écran kiosque, en dehors de la playlist normale. La rotation est suspendue pendant l'affichage de l'URL Spotlight.

Un bandeau « Revenir à la rotation » apparaît avec un compte à rebours (ou reste affiché indéfiniment selon la configuration). Cliquez dessus pour mettre fin au Spotlight et reprendre la rotation normale.

L'onglet Spotlight est également fermé si on le ferme manuellement sur le PC kiosque.

Message sur la télé

Saisissez un texte dans le champ « Message sur la télé » et envoyez-le. Un overlay est injecté dans tous les onglets kiosque actifs via chrome.scripting, et le message s'affiche en surimpression pendant quelques secondes avant de disparaître automatiquement. Idéal pour les annonces rapides (« Réunion dans 5 minutes »).

06

Gestion de playlist

L'onglet Playlist permet d'ajouter, retirer, réordonner les URLs et de définir une durée d'affichage individuelle pour chacune.

Ajouter une URL

Collez l'URL dans le champ en haut de l'onglet Playlist. Un nom optionnel peut être renseigné — sinon le nom de domaine est utilisé. Pour les vidéos YouTube, l'URL est normalisée automatiquement (liens youtu.be, /shorts/, /embed/ sont convertis en youtube.com/watch?v=…).

Durée par URL

Chaque URL peut avoir sa propre durée d'affichage, indépendante de l'intervalle global. Appuyez sur l'URL en mode Modifier pour ouvrir un sélecteur de durée (de 5 secondes à 1 heure). Si aucune durée n'est définie pour une URL, l'intervalle global s'applique.

Réordonner

En mode Modifier (bouton « Modifier » en haut à droite de l'onglet), une poignée glisser-déposer apparaît sur chaque entrée. Les flèches haut/bas sont également disponibles. L'ordre est immédiatement synchronisé avec l'extension.

URLs récentes

Le bouton « Récents » affiche les URLs récemment affichées sur le kiosque, avec leur favicon. Appuyez sur le + pour les ajouter directement à la playlist sans ressaisir l'adresse.

Bibliothèque de playlists

Sauvegarder et restaurer

La bibliothèque permet de nommer et sauvegarder la playlist en cours. Les playlists sauvegardées sont stockées côté serveur Python (pas dans l'extension), ce qui les rend disponibles même après un redémarrage du navigateur.

Chaque entrée de la bibliothèque affiche une mosaïque des favicons des pages. Appuyez sur une playlist pour la charger immédiatement dans l'extension. La playlist actuelle est automatiquement sauvegardée en session à chaque modification, comme sauvegarde de secours.

07

Réglages

L'onglet Réglages regroupe tous les paramètres de rotation, de rafraîchissement et d'horaires. Les modifications sont instantanément appliquées sur le kiosque.

Rotation

Intervalle global
Durée d'affichage par défaut pour chaque URL. Valeurs possibles : 5 s, 10 s, 15 s, 30 s, 1 min, 2 min, 5 min, 10 min, 15 min, 30 min, 1 h. Défaut : 30 secondes.
Recharger les pages
Recharge immédiatement tous les onglets kiosque en une seule action. Utile après une mise à jour de contenu.
Pages actives
Affiche le nombre d'onglets kiosque ouverts et le statut de connexion de l'extension.

Rafraîchissement automatique

Pour éviter que des pages ne deviennent obsolètes (cache expiré, session expirée…), l'extension peut recharger les onglets automatiquement à intervalles réguliers.

Rafraîchissement pages
Intervalle entre deux rechargements automatiques d'un onglet. Défaut : 4 heures. Options : désactivé, 1 h, 2 h, 4 h, 8 h, 12 h, 24 h.
Rafraîchissement Canva
Canva ne se met pas à jour automatiquement quand on modifie une présentation. Ce paramètre recharge les onglets Canva plus souvent (défaut : 5 min) pour que les modifications soient visibles rapidement sur le kiosque.

Horaires d'affichage

Programmation hebdomadaire

Limitez la rotation à des plages horaires précises, par jour de la semaine. En dehors de la plage, la rotation s'arrête automatiquement. Elle reprend au prochain créneau planifié, sans intervention manuelle.

Exemple de configuration par défaut : lundi au vendredi, 08:00 à 18:00.

Activer
Interrupteur pour activer ou désactiver les horaires. Quand désactivé, la rotation tourne 24 h / 24.
Heure début / fin
Plage horaire quotidienne. Format HH:MM. La fin est exclusive.
Jours actifs
Cercles L M M J V S D sélectionnables. Par défaut, les 5 jours ouvrés sont actifs.

Thème de la télécommande

Trois options : Auto (suit le thème système iOS/Android), Sombre ou Clair. Le choix est mémorisé dans le localStorage du navigateur.

Détection d'expiration de session SSO

Reconnexion automatique

Certaines pages d'entreprise (Salesforce, Microsoft 365, Google Workspace…) redirigent vers une page de connexion SSO quand la session expire. L'extension surveille les onglets kiosque : si une URL change vers une page de login connue, elle déclenche un rechargement automatique pour tenter de rétablir la session (cookies persistent, refresh OAuth…).

Les onglets concernés sont signalés avec une icône ⚠️ dans la liste de la playlist sur la télécommande.

08

Sécurité et réseau

Le système est conçu pour une utilisation sur réseau local uniquement. Le trafic ne quitte jamais le LAN.

Token d'authentification Chaque connexion mobile doit présenter un token hexadécimal de 16 caractères (128 bits). La comparaison est faite en temps constant (secrets.compare_digest) pour résister aux attaques de timing. Une connexion sans token valide reçoit auth_error: invalid_token et est immédiatement fermée.
LAN uniquement Le serveur écoute sur 0.0.0.0:8765 — toutes les interfaces du PC kiosque. Il n'est accessible que depuis le même sous-réseau. Il n'y a pas de tunnel vers Internet, pas de relais externe. Votre pare-feu d'entreprise suffit à isoler le service.
Pas de HTTPS Le serveur fonctionne en HTTP non chiffré sur le réseau local. Pour les environnements nécessitant HTTPS, placez un reverse proxy (nginx, Caddy) devant le serveur Python avec un certificat auto-signé ou Let's Encrypt.
QR code et token intégré Le QR code généré encode directement l'URL avec le token en paramètre (?token=…). Le token est ainsi stocké dans le localStorage du téléphone lors du premier scan et réutilisé automatiquement ensuite. Il n'est plus nécessaire de rescanner le QR code après un redémarrage du serveur, sauf si le fichier .wt_token est supprimé.
Extension sans accès réseau sortant L'extension ne se connecte qu'à ws://localhost:8765. Elle n'envoie aucune donnée en dehors du PC kiosque. Les permissions demandées dans manifest.json sont limitées aux onglets, alarmes, scripting et stockage local.

Port et pare-feu

Le serveur utilise le port TCP 8765. Sur Windows, une règle de pare-feu entrant peut être nécessaire si Windows Defender bloque les connexions entrantes. Commande PowerShell (en admin) : 

New-NetFirewallRule -DisplayName "wt-rotate" `
  -Direction Inbound -Protocol TCP `
  -LocalPort 8765 -Action Allow
09

Dépannage

Les problèmes les plus fréquents et leur résolution.

La télécommande affiche « Serveur introuvable »

Le téléphone ne parvient pas à joindre le serveur Python sur le PC kiosque.

  • Vérifiez que python remote_server.py est bien lancé sur le PC kiosque.
  • Téléphone et PC doivent être sur le même réseau Wi-Fi (même sous-réseau).
  • Vérifiez le pare-feu Windows : autorisez le port 8765 en entrée (voir ci-dessus).
  • Vérifiez que l'IP affichée dans le QR code correspond bien à l'IP LAN du PC (pas une IP VPN ou loopback).
  • Si le PC est connecté en câble Ethernet ET Wi-Fi, le serveur peut choisir la mauvaise interface. Arrêtez temporairement l'adaptateur inutilisé.

Le bandeau « Extension non connectée » s'affiche

Le serveur Python tourne, le téléphone est connecté, mais l'extension Chrome ne s'est pas encore connectée au serveur.

  • Vérifiez que l'extension wee rotate est bien chargée dans Chrome (chrome://extensions).
  • Le Service Worker MV3 peut être endormi — ouvrez la popup de l'extension pour le réveiller.
  • Redémarrez l'extension : désactivez puis réactivez-la dans chrome://extensions.
  • Consultez les erreurs Service Worker : chrome://extensions → Détails → Inspecter les vues : service worker.

Alerte « Deux extensions connectées en même temps »

Chrome et Edge ont tous les deux l'extension chargée et se connectent simultanément au serveur. Les deux envoient leur état, créant des conflits.

  • Allez dans chrome://extensions et edge://extensions.
  • Désactivez ou supprimez l'extension dans le navigateur que vous n'utilisez pas comme kiosque.
  • Redémarrez le serveur Python après correction.

Le QR code doit être rescanné après chaque redémarrage

Le token change à chaque démarrage du serveur si le fichier .wt_token n'est pas persisté.

  • Vérifiez que le fichier .wt_token existe dans le dossier wt-rotate et est accessible en écriture.
  • Ne supprimez pas ce fichier volontairement sauf si vous souhaitez renouveler le token.

Les pages de login SSO s'affichent sur le kiosque

Une session expirée redirige vers une page d'authentification (Microsoft 365, Google, Salesforce…).

  • L'extension tente une reconnexion automatique — attendez quelques secondes.
  • Si le rechargement ne suffit pas, connectez-vous manuellement sur le PC kiosque une fois pour renouveler les cookies.
  • Réduisez l'intervalle de rafraîchissement automatique des pages (Réglages → Rafraîchissement auto) pour que l'extension recharge plus souvent et maintienne la session.
  • Certains SSO nécessitent une interaction humaine — envisagez un compte de service dédié avec session persistante.

Les Canva ne se mettent pas à jour

Canva ne rafraîchit pas automatiquement les présentations modifiées dans un onglet déjà ouvert.

  • Le rafraîchissement Canva automatique est activé par défaut (5 min). Vérifiez qu'il n'a pas été désactivé dans les Réglages.
  • Pour forcer une mise à jour immédiate : Réglages → « Recharger les pages ».

La rotation ne démarre pas / s'arrête toute seule

  • Si les horaires sont activés, vérifiez que l'heure actuelle est dans la plage configurée.
  • Vérifiez que la playlist contient au moins 2 URLs avec des adresses valides.
  • Si les onglets kiosque ont été fermés manuellement, l'extension réinitialise son état. Relancez la rotation depuis la popup de l'extension ou depuis la télécommande.
  • Consultez le journal de l'extension : chrome://extensions → service worker → onglet Console.

L'aperçu en direct ne s'affiche pas

  • L'aperçu n'est disponible que si la rotation est active et l'extension connectée.
  • Les captures sont mises en cache 30 secondes côté serveur. Si la connexion a été coupée puis rétablie, l'image apparaît dès la reconnexion si elle date de moins de 30 s.
  • Certaines pages avec politique CSP stricte peuvent bloquer la capture par chrome.tabs.captureVisibleTab. Ce n'est pas un bug — c'est une protection de la page cible.
